## 1. 提案の目的と設計規律

本書は、`Drafts/` で議論・精緻化された成果を、基底リポジトリ `RDL_Core` へ正式に統合・昇格させるための改定案セットである。

本改定では、以下の**厳格な階層規律（自己同一性と責務の分離）**を徹底している。

```text
T0 (基底措定・最低動作)
  何が成立していれば動けるか（状態・拘束）
  ※ M_B の生成史までは語らない

T1 (SILN操作プロトコル)
  それがどう形成・代謝されるか（形成経路・抽象代謝工程）
  Probe_B(interaction) → {Δ}_B (with ξ' ≠ 0) → 展開 → Inspection → Selection → Reconstruction

T2 (汎用機能・道具層)
  その工程で利用可能な汎用の検査・評価機構（道具）を提供する

各系設計 (Human / AI / 組織 / 物理系)
  Probe の身体／インターフェースと、Selection の具体基準・許容損失を実装する
```

## 2. v1.3 における精密化ポイント

1. **因果表現の純化（$\xi \to E$ ではない）**:
   * $\xi$ は誤差 $E$ の直接の原因ではない（$E$ は SPEC 上あくまで $F$ と $F'$ の不整合）。
   * BASE から言えるのは「有限境界 $B$ には $\xi$ が残存するため、現在の構造が将来の相互作用を完全に回収し尽くすことは保証されない（非終端閉包性）。そのため新たな差異が代謝対象として現れうる」という開かれた関係性である。
2. **`Probe` 表記の厳密化（$\xi'$ は出力ではなく残存条件）**:
   * $\xi'$ が Probe 関数の生成・計算物に見えるのを避けるため、表記を以下に純化：
     ```text
     Probe_B(interaction) → {Δ}_B
     with ξ'(B) ≠ 0
     ```
   * Probe が刈り取るのは $B$ 内の差分列 $\{\Delta\}_B$ であり、$\xi'$ はその外側に必然的に残存する条件であることを明記。
3. **構造発生論の分離・保留**:
   * ランダムウォーク積分（履歴蓄積、偏りの検出）などの具体的メカニズムは、基底（T0/T1）に焼き込まず、下流の「構造発生論」として拡張可能な余白を残した。
