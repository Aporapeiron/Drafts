# T0 最低動作仕様（SPEC）

*RDL基盤層 / SPEC / 統合改定案 v1.2*  
*英語名：Minimum Operational Specification / 文書コード：SPEC*  
*依存：T0 基底措定（BASE）*

---

## 1. 目的と適用範囲

本文書は、RDLが最低限実行できなければならない中核動作を定める。基底となる考え方は **T0 基底措定（BASE）** に依存する。本仕様では、哲学的な理由づけを繰り返さず、動作上必要な定義・機能要件・状態遷移を記述する。

### 1.1 認識上の前提

RDLは、世界そのものを直接記述または取得するとは仮定しない。RDLが直接に扱うのは、有限境界 $B$ を通じて形成された**抽象化された解釈・予測**と、それらの後続的な差異である。

この前提により、`EFP` も世界そのものではなく、RDLの境界内で作用として扱われる未解釈の作用束を意味する。また、`F` と `F'` は世界の状態そのものではなく、同じ更新前の $M_B$ が異なる入力から形成した解釈状態である。したがって、`E` は世界そのものと内部表象との差ではなく、解釈・予測の間に検出される不整合として扱う。

> **RDLにとって、直接に扱えるのは世界そのものではなく、有限境界 $B$ を通じて形成された解釈である。**

### 1.2 通常運転と高負荷再編の二重構造

RDLの最低動作は、以下の2つの状態遷移を包括する。
1. **通常運転（巡航代謝）**: 既存の $M_B$ を用いて入力を軽量に解釈・予測・局所比較する（$H < \theta$）。
2. **再編相 $M_\Delta$（高負荷代謝）**: 既存の $M_B$ では吸収できない不整合が限界に達したとき（$H \ge \theta$）、既存構造そのものを対象化・解剖し、未知から次の $M_B'$ を再構成する（形成経路の詳細はT1が規定）。

本仕様は次の二層で構成する。

| 層 | 役割 | 置換可能性 |
|---|---|---|
| **Core Requirement** | RDLとして最低限必要な抽象機能 | 満たすべき機能を変更しない |
| **Standard Model** | Core Requirementを実現する標準的な式・状態・局所モデル | 同等以上の機能を満たすモデルへ置換できる |

## 2. 中核変数

| 記号 | 名称 | 最低限の意味 |
|---|---|---|
| `B` | 有限境界 | 観測・認識・記述・操作のための有限な選択枠組み |
| `ξ` | 未回収関係 | 有限境界に伴って残る関係（非ランダム・未回収の全体） |
| `M_B` | 整合慣性 | `B` のもとで一時的に保持され、現在の解釈・予測・応答を拘束する自己側の有限整合構造（身体） |
| `SILN` | 操作対象構造 | `B` のもとで切り出された対象側の有限構造 |
| `EFP` | 素流圧 | `B` の内部で作用として扱われる、`M_B` へ作用する未解釈の作用束 |
| `F` | 作用解釈・予測 | `EFP` が `M_B` を通して解釈され、現在構造から形成された作用情報・予測 |
| `F'` | 後続作用解釈 | 後続する `EFP'` を、**更新前の同一の `M_B`** が解釈して形成した次の作用情報 |
| `E` | 慣性誤差 | `F` が含む予測と、後続して形成された `F'` との差異 |
| `H` | 熱・誤差蓄積 | `E` のうち、現在構造で吸収・解消されず、残存・蓄積・伝播した状態 |
| `θ` | 判定境界 | 通常維持（局所更新）と高負荷再編（$M_\Delta$）を分ける判定条件 |
| `M_Δ` | 再編相 | `H ≥ θ` により既存構造そのものを検査対象化し、未知探索・再編を行う高負荷状態 |

`B` 依存構造（`M_B`、SILN、更新後の `M_B'` など）は、BASEの `[B-ξ]` に従い、特記がなくても $\xi$ を伴う。

## 3. Core Requirement

RDLの最低動作は、以下の機能を満たさなければならない。

| ID | 必須機能 |
|---|---|
| **C1** | 有限境界 `B` を設定できる。 |
| **C2** | `B` 依存構造に `ξ` 残存を付与・継承できる。 |
| **C3** | `M_B` が作用 `EFP` を `F` として解釈し、予測を形成できる。 |
| **C4** | 現在構造から形成された予測 `F` と、後続入力から形成された `F'` との差異を `E` として扱える。 |
| **C5** | `E` のうち吸収・解消されない残存・蓄積・伝播を `H` として扱える。 |
| **C6** | `H` その他の状態から、維持・局所更新と再編（$M_\Delta$）を分ける判定境界 `θ` を設定できる。 |
| **C7** | 判定結果に応じ、`H < θ` のときは `M_B` を維持・局所更新し、`H ≥ θ` のときは再編相 `M_Δ` へ移行できる。 |
| **C8** | `M_Δ` を経て再構成された更新後の `M_B'` も `B` 依存であり、`ξ` を継承する。 |
| **C9** | RDL自身を通常の操作対象として扱える（自己例外化禁止）。 |

## 4. 最低動作フロー

自己側の基本動作は、通常運転の比較ループと、閾値超過時の再編相 $M_\Delta$ への分岐として記述する。

```text
【通常運転（H < θ：既知の巡航）】
EFP
 ↓ M_Bによる解釈・予測
F
 │
 │ 後続入力
 ↓
EFP'
 ↓ 同一の更新前 M_B による解釈
F'
 ↓ Fとの予測差異
E
 ↓ 吸収・解消されない差異の残存・蓄積・伝播
H
 ↓ θによる判定
 ├─ [ H < θ ] ──→ 維持・局所更新（通常運転継続）
 │
 └─ [ H ≥ θ ] ──→ 【再編相 M_Δ（未知高負荷代謝）】
                    ↓ 既存 M_B の対象化・解体
                    ↓ 未知探索・Probe・検査・Selection（T1操作）
                    ↓ 残存関係の抽出・再構成
                   M_B' （新構造として通常運転へ復帰）
```

圧縮表記は次のとおりである。

```text
EFP → F
         \
          Δ(F,F') → E → H → θ ──[ H < θ ]──→ Update_local(M_B)
         /                          │
EFP' → F'                           └──[ H ≥ θ ]──→ M_Δ ──→ M_B'
```

* 通常運転において `F'` の形成には、更新後の `M_B'` ではなく、更新前の同一の `M_B` を用いる（安価な反実仮想的比較器としての動作）。
* `H ≥ θ` に達したとき、系は $M_\Delta$ へ移行し、T1の高負荷代謝（未知探索・選別・再構成）を起動する。

## 5. 抽象更新則

具体的な時間形式やアルゴリズムは固定しない。最低限、更新は次の抽象形式で表現できなければならない。

```text
M_B' = Update(M_B, F, E, H, θ, ξ)
```

差分形式：
```text
ΔM_B = U(M_B, F, E, H, θ, ξ)
```

連続時間、離散時間、確率的更新、イベント駆動、状態遷移、ニューラル更新などは、C1〜C9を満たす限り排除しない。

## 6. Standard Model

以下は必須定義ではなく、RDLで使用する標準的な具体化である。

### 6.1 解釈と誤差

```text
F(t)      = interp(M_B, EFP(t))
F'(t+Δ)   = interp(M_B, EFP(t+Δ))

E(t+Δ)    = Δ(F, F')
```

### 6.2 蓄積と更新

```text
H = ||H_vec||
H_vec ≡ δM_B(t)

dM_B/dt = f(M_B, E, ξ)
```

### 6.3 判定と相状態

```text
H < θ  → 維持・局所更新（M_act または M_lat）
H ≥ θ  → 再編相 M_Δ への移行
```

相状態の遷移列：
```text
M_B → [ H ≥ θ ] → M_Δ → [ Selection & Reconstruction ] → M_B'
```

* `M_Δ` 内部では、既存の $M_B$ そのものが検査対象（SILN_SELF）となり、T1の代謝処理によって新たな $M_B'$ が析出・再構成される。

### 6.4 任意の補助モデル

```text
θ_eff(t) = θ + g(ξ(t))
||M_B|| · D[ξ] = 𝒦
```

## 7. 標準モデルの差替規約

標準モデルを差し替える場合は、少なくとも次の対応を明示する。

| 確認項目 | 明示する内容 |
|---|---|
| `E` | `F` による何の予測と、どの後続 `F'` との何を差異として検出するか |
| `H` | 何を蓄積・残存状態として扱うか |
| `θ` | 何を維持と再編（$M_\Delta$ 移行）の判定境界とするか |
| `M_Δ` | 高負荷再編相への移行条件、T1代謝への受渡条件、および $M_B'$ への復帰条件をどう保持するか |
| 更新 | どの条件で $M_B'$ へ遷移・復帰するか |
| `ξ` | 有限境界に伴う未回収関係をどう保持するか |

## 8. T0 / T1 / T2 / 各系設計の責務分担

| 層 | 責務 |
|---|---|
| **T0** | RDLの基底措定、最低動作、維持／再編（$M_\Delta$）の起動判定を保持する。 |
| **T1** | 通常のSILN操作に加え、$M_\Delta$ における高負荷代謝（Probe $\to$ 展開 $\to$ 検査 $\to$ Selection $\to$ 再構成）の抽象手順を規定する。 |
| **T2** | Selection 等に利用可能な汎用検査・評価機構（道具：耐久検査など）を提供する。 |
| **各系設計** | Probe の身体／センサ／API 実装と、Selection の具体基準・許容損失を設計する。 |

## 9. 改訂履歴

- **v1.2 (責務境界の完全化)**：
  - 標準モデル差替規約の `M_Δ` を「移行条件、T1代謝への受渡条件、復帰条件」へと純化（内部処理をT1へ完全委任）。
- **v1.0 (統合改定案)**：
  - 依存先を「基底措定（BASE）」へ更新。
  - 通常運転（$H < \theta$）と再編相 $M_\Delta$（$H \ge \theta$）の二段構えを明文化。
  - T0/T1/T2/各系設計の4層責務分担を導入。
- **v0.8**：世界そのものを直接扱わず、有限境界 $B$ のもとで形成された解釈・予測を扱う認識前提を追加。
- **v0.7**：同一更新前 $M_B$ による $F'$ の導入。
