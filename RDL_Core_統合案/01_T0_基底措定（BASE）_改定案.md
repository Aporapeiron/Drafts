# T0 基底措定（BASE）

*RDL基盤層 / BASE / 統合改定案 v2.0*  
*英語名：Foundational Postulates / 文書コード：BASE*  
*参照：RDL_関係拘束強度_基底概念変更案_v0.3*

---

## 1. 目的と責務

本文書は、関係力学言語（RDL）がどのような基底措定を採用しているかを定める。  
ここでいう**措定**とは、世界について終端的に確定された真理ではなく、**後続の仕様および操作を成立させるために基底へまず置く、再検査可能な条件**をいう。

本文書は、具体的な計算法、更新アルゴリズム、数値モデルを定めない。それらは **T0 最低動作仕様（SPEC）** に記載する。また、構造がどのように生成・代謝されるかの形成経路は **T1（SILN操作層）** に記載する。

---

## 2. 基底措定

| ID | 措定名 | 内容 |
|---|---|---|
| **B1** | 関係ネットワークと関係拘束 | 基底記述には、孤立した実体ではなく、相互接続された非線形関係ネットワークを採用する。<br/>有限境界 $B$ に取り込まれた関係および関係束は均質ではなく、現在の解釈・予測・選択・応答・更新の可能域を異なる程度に拘束する。<br/>この拘束は、対象・時点・境界・問い・関係位置によって変化し、絶対的真理性を意味しない。 |
| **B2** | 有限境界 | 観測・認識・記述・操作には、対象、尺度、語彙、差異、用途などを選択する有限境界 $B$ が必要である。 |
| **B3** | 非終端閉包性 | 有限境界 $B$ による閉包が、完全な終端的閉包になるとは保証しない。 |
| **B4** | `B-ξ` 残存性 | 有限境界 $B$ を引くと、回収されない関係 $\xi$ が必ず残る。 |
| **B5** | 自己例外化禁止 | RDL自身、その語彙、公理、措定、仕様も、RDLの観測・検査・操作の対象になりうる。 |

基底規則は次の一式に圧縮できる。

```text
∀B_finite: ξ(B) ≠ 0
```

$\xi$ は閉包後に追加される外来ノイズではなく、有限境界を引くことに伴って必然的に生じる未回収関係である。また、$B$ に依存する構造は、特記がない限り $\xi$ を暗黙に伴う。

## 3. 基本概念の階層

RDLでは、次の概念を同一階層の要素として扱わない。

| 階層 | 概念 | 役割 |
|---|---|---|
| **基底** | 関係ネットワーク | あらゆる構造の基底記述 |
| **操作条件** | $B$ | 有限化・切り出しを行う選択枠組み |
| **残存条件** | $\xi$ | 有限化に伴う未回収関係 |
| **有限構造** | $M_B$ | **有限関係拘束構造**。<br/>$B$ のもとで一時的に保持され、現在の解釈・予測・選択・応答・更新を拘束する自己側の有限構造（身体） |
| **有限構造** | SILN | 対象側へ切り出された操作対象構造（食材） |
| **運動概念** | Aporapeiron | $\xi$ を伴う有限構造が、再切り出し・検査・更新・再構成へ開かれ続ける非終端的な関係運動 |

したがって、$M_B$ と SILN は有限構造であり、$\xi$ はその有限化に伴う残存条件である。Aporapeiron は、それらが変化し続ける運動全体を指す。

## 4. 関係拘束と関係拘束強度

### 4.1 定義

```text
関係拘束 :=
ある関係または関係束が、有限境界 B のもとで、
現在取りうる解釈・予測・選択・応答・更新の可能域を狭める作用。

関係拘束強度 :=
その拘束が、特定の断面においてどの程度強く現れているかを表す性質。
```

### 4.2 拘束の基本的性質

1. **相対性**: 関係拘束強度は、関係そのものに固定された絶対値ではない。問い・対象・時点・境界・用途との関係において相対的に立ち上がる。
2. **非真理性**: 関係拘束強度が高いことは「真である（事実そのものである）」ことを意味しない。有限境界 $B$ がある限り、いかに強い拘束のもとでも $\xi$ は残存する（$[B\text{-}\xi]$）。
3. **断面化**: 慣性、重み、結晶度、権限拘束、情報源の拘束力などは、関係拘束強度が異なる断面（時間、判断、固定化、制度、ソース）に現れた表現として扱いうる。
4. **競合と不整合**: 複数の強い関係拘束同士が競合する場合、それ自体が不整合 $E$ や高負荷再編相 $M_\Delta$ の契機になりうる。

## 5. Aporapeiron

```text
Aporapeiron :=
有限境界 B によって有限関係拘束構造が成立しても ξ が残存し、
その構造が終端化されず、再切り出し・更新・再構成を通じて
別の有限構造へ移行し続けうる非終端的な関係運動。
```

Aporapeiron は特定の表現形式を意味しない。空間、グラフ、時間列、状態遷移、階層、代数などは、有限構造を扱うための道具として選択できる。いずれの表現も基底実体として特権化せず、採用した表現自体も有限境界と $\xi$ に依存する。

## 6. 措定と自己適用

RDLが観測・記述・操作によって得た構造は、終端的確定ではなく、改訂可能な措定として保持する。真理、神、実在、虚構、科学理論、数などの強いラベルを禁止または否定するのではなく、対象化された時点で通常の有限構造として扱う。

RDL自身も例外ではない。

```text
M_B(RDL)
  → SILN_SELF(RDL)
  → 検査・選別・再構成
  → M_B'(RDL) with ξ' ≠ 0
```

更新後のRDLも再び有限構造であり、再対象化・再検査・再更新の対象となる。この自己適用は B5（自己例外化禁止）に基づく。

## 7. SPECとの境界

| 文書 | 定めるもの | 定めないもの |
|---|---|---|
| **本文書（BASE）** | 基底措定、関係拘束の基本性質、概念階層、`B-ξ`、自己例外化禁止、Aporapeironの位置づけ | 具体的な計算式、閾値、更新アルゴリズム、代謝・形成経路 |
| **T0 最低動作仕様（SPEC）** | 必須動作、変数、巡航と再編（$M_\Delta$）の状態遷移、標準モデル | BASEを覆す新たな基底措定 |

> **圧縮定義**：RDLは、関係ネットワークに有限境界 $B$ を引くと、有限関係拘束構造 $M_B$ とともに未回収関係 $\xi$ が残ると措定する。したがって、構造とRDL自身を終端的に固定せず、検査・更新・再構成へ開かれた関係運動として扱う。
