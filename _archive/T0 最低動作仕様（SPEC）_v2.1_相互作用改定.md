# T0 最低動作仕様（SPEC）

*RDL基盤層 / SPEC / 統合改定案 v2.1*  
*英語名：Minimum Operational Specification / 文書コード：SPEC*  
*依存：T0 基底措定（BASE）*  
*参照：RDL_関係拘束強度_基底概念変更案_v0.3*  
*改定主題：相互作用断面としてのEFP*

---

## 1. 目的と適用範囲

本文書は、RDLが最低限実行できなければならない中核動作を定める。基底となる考え方は **T0 基底措定（BASE）** に依存する。本仕様では、哲学的な理由づけを繰り返さず、動作上必要な定義・機能要件・状態遷移を記述する。

### 1.1 認識上の前提

RDLは、世界そのものを直接記述または取得するとは仮定しない。RDLが直接に扱うのは、有限境界 $B$ を通じて切り出された作用断面と、それを通じて形成された**抽象化された解釈・予測**、およびそれらの後続的な差異である。

この前提により、`EFP` も世界そのものではない。また、独立した単純な外生入力であることも要求しない。`EFP` は、関係ネットワーク上で進行する相互作用のうち、有限境界 $B$ の内部で特定の $M_B$ に対する作用として切り出された**未解釈の作用束**を意味する。

`F` と `F'` は世界の状態そのものではなく、同じ更新前の $M_B$ が異なる時点の作用断面から形成した解釈状態である。したがって、`E` は世界そのものと内部表象との差ではなく、解釈・予測の間に検出される**不整合**として扱う。

> **RDLにとって、直接に扱えるのは世界そのものでも相互作用全体でもなく、有限境界 $B$ から切り出された作用断面と、それを通じて形成された解釈である。**

### 1.2 相互作用とEFPの断面運用

BASEが基底に置くのは相互作用である。一方、最低動作では相互作用系全体を常に展開せず、特定の $M_B$ を基準に、そこへ現れた方向付き作用断面を `EFP` として扱う。

```text
関係ネットワーク上の相互作用
          ↓  B・観測位置・時間断面・対象方向による切り出し
        EFP
          ↓
      interp(M_B, EFP)
          ↓
          F
```

`EFP` の内部生成過程は複雑でありうる。そこには、複数の構造、他の解釈系、関係履歴、環境、媒介構造、先行する作用・応答、未回収関係 $\xi$ などが関与しうる。

ただし、最低動作ではこれらを毎回展開することを要求しない。`EFP` は、必要な操作断面において一つの未解釈作用束として扱ってよい。

また、後続する `EFP'` は、先行する `EFP` と独立した外生入力である必要はない。先行する $M_B$ の解釈・選択・応答が関係系を変化させ、その変化が次の `EFP'` の生成条件へ回り込んでよい。

```text
EFP_t → interp(M_B, EFP_t) → F_t → 応答・作用
                                      ↓
                               相互作用条件が変化
                                      ↓
                                  EFP_{t+Δ}
```

この循環を認めても、最低動作上は各時点の `EFP` を方向付き断面として扱うことで、解釈・比較・更新の式を簡潔に維持できる。

### 1.3 通常運転と高負荷再編の二重構造

RDLの最低動作は、以下の2つの状態遷移を包括する。

1. **通常運転（巡航代謝）**: 既存の有限関係拘束構造 $M_B$ を用いて作用断面を軽量に解釈・予測・局所比較する（$H < \theta$）。
2. **再編相 $M_\Delta$（高負荷代謝）**: 既存構造では保持・吸収できない不整合が限界に達したとき（$H \ge \theta$）、既存拘束構造そのものを対象化・解剖し、未知から次の $M_B'$ を再構成する（形成経路の詳細はT1が規定）。

本仕様は次の二層で構成する。

| 層 | 役割 | 置換可能性 |
|---|---|---|
| **Core Requirement** | RDLとして最低限必要な抽象機能 | 満たすべき機能を変更しない |
| **Standard Model** | Core Requirementを実現する標準的な式・状態・局所モデル | 同等以上の機能を満たすモデルへ置換できる |

## 2. 中核変数

| 記号 | 名称 | 最低限の意味 |
|---|---|---|
| `B` | 有限境界 | 観測・認識・記述・操作のための有限な選択枠組み |
| `ξ` | 未回収関係 | 有限境界に伴って残る関係（非ランダム・未回収の全体） |
| `M_B` | 有限関係拘束構造 | `B` のもとで一時的に保持され、現在の解釈・予測・選択・応答・更新を拘束する自己側の有限構造（身体） |
| `SILN` | 操作対象構造 | `B` のもとで切り出された対象側の有限構造 |
| `EFP` | 素流圧 | 関係ネットワーク上の相互作用から、`B` の内部で特定の `M_B` に対する作用として切り出された未解釈の作用束。内部生成過程は複雑でよく、独立外生入力であることを要求しない |
| `F` | 作用解釈・予測 | `EFP` が `M_B` を通して解釈され、現在構造から形成された作用情報・予測 |
| `F'` | 後続作用解釈 | 後続する `EFP'` を、**更新前の同一の `M_B`** が解釈して形成した次の作用情報。`EFP'` は先行相互作用の影響を含んでよい |
| `E` | 不整合 | `F` が含む予測と、後続して形成された `F'` との差異 |
| `H` | 熱・不整合蓄積 | `E` のうち、現在構造で吸収・解消されず、残存・蓄積・伝播した状態 |
| `θ` | 判定境界 | 既存の関係拘束構造が未解消不整合 `H` を内部で保持・吸収し続けられる限界 |
| `M_Δ` | 再編相 | `H ≥ θ` により既存拘束構造そのものを検査対象化し、未知探索・再編を行う高負荷状態 |
| `C_rel`（任意補助） | 関係拘束強度 | 関係または関係束が特定断面で可能域をどの程度拘束するかを表す性質（Core必須ではなく任意補助概念） |

`B` 依存構造（`M_B`、SILN、更新後の `M_B'` など）および `B` から切り出された作用断面は、BASEの `[B-ξ]` に従い、特記がなくても $\xi$ を伴う。

## 3. Core Requirement

RDLの最低動作は、以下の機能を満たさなければならない。

| ID | 必須機能 |
|---|---|
| **C1** | 有限境界 `B` を設定できる。 |
| **C2** | `B` 依存構造および作用断面に `ξ` 残存を付与・継承できる。 |
| **C3** | 相互作用から `M_B` 側へ切り出された作用断面 `EFP` を、`M_B` が `F` として解釈し、予測を形成できる。 |
| **C4** | 現在構造から形成された予測 `F` と、後続する作用断面 `EFP'` から形成された `F'` との差異を不整合 `E` として扱える。`EFP'` は先行相互作用から独立である必要はない。 |
| **C5** | `E` のうち吸収・解消されない残存・蓄積・伝播を熱 `H` として扱える。 |
| **C6** | `H` その他の状態から、維持・局所更新と再編（$M_\Delta$）を分ける判定境界 `θ` を設定できる。 |
| **C7** | 判定結果に応じ、`H < θ` のときは `M_B` を維持・局所更新し、`H ≥ θ` のときは再編相 `M_\Delta` へ移行できる。 |
| **C8** | `M_\Delta` を経て再構成された更新後の `M_B'` も `B` 依存であり、`ξ` を継承する。 |
| **C9** | RDL自身を通常の操作対象として扱える（自己例外化禁止）。 |
| **C10** | `EFP` を単純な独立外生入力へ固定せず、必要な場合にはその生成条件を相互作用由来の構造として再対象化できる。 |

## 4. 最低動作フロー

自己側の基本動作は、相互作用全体から切り出された作用断面を入力単位とし、通常運転の比較ループと、閾値超過時の再編相 $M_\Delta$ への分岐として記述する。

### 4.1 操作断面

```text
【相互作用系】
    ↓ B・観測位置・時間断面・対象方向による切り出し
EFP
 ↓ M_B による解釈・予測
F
```

ここで `EFP` の内部生成過程を展開する必要はない。ただし `M_B` の応答・作用が相互作用系へ戻り、後続 `EFP'` の成立条件を変化させることを妨げない。

### 4.2 通常運転と再編

```text
【通常運転（H < θ：既知の巡航）】
EFP
 ↓ M_B による解釈・予測
F
 │
 │ 後続する相互作用から切り出された作用断面
 ↓
EFP'
 ↓ 同一の更新前 M_B による解釈
F'
 ↓ Fとの予測差異
E (不整合)
 ↓ 吸収・解消されない差異の残存・蓄積・伝播
H (熱)
 ↓ θによる判定
 ├─ [ H < θ ] ──→ 維持・局所更新（通常運転継続）
 │
 └─ [ H ≥ θ ] ──→ 【再編相 M_Δ（未知高負荷代謝）】
                    ↓ 既存 M_B の対象化・解剖
                    ↓ 未知探索・Probe・検査・Selection（T1操作）
                    ↓ 残存関係の抽出・再構成
                   M_B' （新構造として通常運転へ復帰）
```

圧縮表記は次のとおりである。

```text
EFP → F
         \
          Δ(F,F') → E → H → θ ──[ H < θ ]──→ Update_local(M_B)
         /                          │
EFP' → F'                           └──[ H ≥ θ ]──→ M_Δ ──→ M_B'
```

* 通常運転において `F'` の形成には、更新後の `M_B'` ではなく、更新前の同一の `M_B` を用いる（安価な反実仮想的比較器としての動作）。
* `EFP'` は単なる独立した次入力ではなく、先行する `M_B` の応答を含む相互作用の結果として変化していてよい。
* `H ≥ θ` に達したとき、系は $M_\Delta$ へ移行し、T1の高負荷代謝（未知探索・選別・再構成）を起動する。

## 5. 抽象更新則

具体的な時間形式やアルゴリズムは固定しない。最低限、更新は次の抽象形式で表現できなければならない。

```text
M_B' = Update(M_B, F, E, H, θ, ξ)
```

差分形式：

```text
ΔM_B = U(M_B, F, E, H, θ, ξ)
```

この更新則は `M_B` 側の最低動作断面を表すものであり、相互作用系全体の状態更新を完全記述する式ではない。

連続時間、離散時間、確率的更新、イベント駆動、状態遷移、ニューラル更新などは、C1〜C10を満たす限り排除しない。

## 6. Standard Model

以下は必須定義ではなく、RDLで使用する標準的な具体化である。

### 6.1 解釈と不整合

```text
F(t)      = interp(M_B, EFP(t))
F'(t+Δ)   = interp(M_B, EFP(t+Δ))

E(t+Δ)    = Δ(F, F')
```

この式は、相互作用全体を一方向因果へ還元するものではない。各時点で特定の $M_B$ に対して切り出された作用断面を比較するための局所モデルである。

#### EFP生成過程の任意展開

必要な場合に限り、後続 `EFP` の生成条件を概念的に次のように展開できる。

```text
EFP(t+Δ)
  = Section_B(
      Interaction(
        prior_state,
        environment,
        other_structures,
        response(M_B, F(t)),
        ξ,
        ...
      )
    )
```

右辺の内部構造を固定することは Core Requirement ではない。対象ごとに異なる相互作用モデルを採用でき、通常運転では右辺全体を畳んで `EFP(t+Δ)` として扱ってよい。

複数の解釈系が相互作用する場合、それぞれの `interp` の出力に基づく応答が、相手側の後続 `EFP` の生成条件へ入りうる。

```text
F_A = interp(M_A, EFP_{B→A})
F_B = interp(M_B, EFP_{A→B})

response_A → condition(EFP_{A→B}')
response_B → condition(EFP_{B→A}')
```

ここで重要なのは `interp_A` と `interp_B` が同じ解釈を持つことではなく、**それぞれの解釈に基づく応答が互いの後続作用条件へ接続される**ことである。解釈や予測の不一致が大きい場合、その戻り作用は不整合 `E` の主要な発生源になりうる。

### 6.2 蓄積と更新（整合慣性の断面化）

従来「整合慣性」と呼ばれていた性質は、関係拘束強度の時間・更新抵抗断面 $I(M_B)$ として扱う。

```text
I(M_B) ↑ → 既存の解釈・更新経路への拘束が強い → 局所入力による変形率 κ ↓
```

```text
H = ||H_vec||

H_vec := E のうち、現在の M_B によって吸収・解消されず残存している不整合状態
（局所変形全体を δM_B(t) と置く場合、未解消成分 H_vec = P_unresolved(δM_B(t))）

dM_B/dt = f(M_B, E, ξ)
```

#### 熱 H の残存と時間幅による蓄積（概念補足）

$E$ のうち現在構造で吸収・解消された部分は局所更新として解消され、$H$ には残らない（揺らぎ $\neq 0$ であっても $H \approx 0$ は可能）。未吸収分のみが $H$ として残存する。

```text
H_{n+1} = Remain(H_n, Δt) + Residual(E_{n+1}, M_B, B, ...)
```

* 小さい不整合 $E$ でも、解消時間不足の短時間反復があれば残存 $H$ が加算されて $\theta$ を超えうる。
* 十分に大きい不整合 $E$ であれば、単発の入力で直ちに $H \ge \theta$ となり再編相へ至る。
* 相互作用系では、ある応答が後続 `EFP` を変え、類似の不整合を反復生成または減衰させる場合がある。したがって、$H$ の蓄積は外部入力列だけでなく相互作用ループの性質にも依存しうる。

#### 実効拘束 C_eff（任意補助概念）

未吸収不整合の蓄積 $H$ は、既存拘束構造の実効的な保持余力を揺らしうる。概念的には、現在状態における実効拘束を以下のように表現できる。

```text
C_eff = f(C_rel, H, B, ...)
```

※ ただし、防衛的固定化なども許容するため、$H \uparrow \to C_{rel} \downarrow$ を普遍的な単調則として固定しない。

### 6.3 判定と相状態

```text
H < θ  → 維持・局所更新（M_act または M_lat）
H ≥ θ  → 再編相 M_Δ への移行
```

相状態の遷移列：

```text
M_B → [ H ≥ θ ] → M_Δ → [ Selection & Reconstruction ] → M_B'
```

* `M_\Delta` 内部では、既存の $M_B$ そのものが検査対象（SILN_SELF）となり、T1の代謝処理によって新たな $M_B'$ が析出・再構成される。

### 6.4 任意の補助モデル

```text
θ_eff(t) = θ + g(ξ(t))
||M_B|| · D[ξ] = 𝒦
```

## 7. 標準モデルの差替規約

標準モデルを差し替える場合は、少なくとも次の対応を明示する。

| 確認項目 | 明示する内容 |
|---|---|
| `EFP` | 相互作用のどの断面を、どの `B`・観測位置・時間・対象方向から作用束として切り出すか。独立外生入力を仮定する場合は、その仮定範囲も示す |
| `E` | `F` による何の予測と、どの後続 `F'` との何を不整合として検出するか |
| `H` | 何を蓄積・残存状態として扱うか |
| `θ` | 何を維持と再編（$M_\Delta$ 移行）の判定境界とするか |
| `M_Δ` | 高負荷再編相への移行条件、T1代謝への受渡条件、および $M_B'$ への復帰条件をどう保持するか |
| 更新 | どの条件で $M_B'$ へ遷移・復帰するか |
| `ξ` | 有限境界に伴う未回収関係をどう保持するか |

## 8. T0 / T1 / T2 / 各系設計の責務分担

| 層 | 責務 |
|---|---|
| **T0** | RDLの基底措定、相互作用からの作用断面化、最低動作、維持／再編（$M_\Delta$）の起動判定を保持する。 |
| **T1** | 通常のSILN操作に加え、$M_\Delta$ における高負荷代謝（Probe $\to$ 展開 $\to$ 検査 $\to$ Selection $\to$ 再構成）の抽象手順を規定する。必要に応じてEFPの生成条件自体を対象化・展開する。 |
| **T2** | Selection 等に利用可能な汎用検査・評価機構（道具：耐久検査など）を提供する。 |
| **各系設計** | 相互作用系の具体モデル、Probe の身体／センサ／API 実装、EFPの具体的切り出し方法、Selection の具体基準・許容損失を設計する。 |

## 9. 改訂履歴

- **v2.1（相互作用・EFP断面改定案）**：
  - `EFP` を独立外生入力ではなく、相互作用から `M_B` 側へ切り出された未解釈の作用束として再定義。
  - `EFP` の内部生成過程が複雑であり、複数構造・履歴・環境・先行応答を含みうることを明記。
  - `M_B` の応答が相互作用系へ戻り、後続 `EFP'` の生成条件を変化させうることを追加。
  - Core Requirement にEFP生成条件の再対象化可能性を追加。
  - Standard Model の基本式 `F = interp(M_B, EFP)` は維持し、相互作用展開を任意補助モデルとして追加。
  - 複数 `interp` の接続と、不整合 `E` の相互作用的発生を概念補足として追加。
- **v2.0（関係拘束改定案）**：
  - $M_B$ の名称を「有限関係拘束構造」に変更。
  - $E$ の名称を「不整合」へ純化（旧称：慣性誤差）。
  - 整合慣性を関係拘束強度の時間・更新抵抗断面として再位置づけ。
  - $H$ の時間幅残存モデル、実効拘束 $C_{eff}$、$\theta$ の保持限界解釈を Standard Model 概念補足として明文化。
- **v1.2**：標準モデル差替規約の $M_\Delta$ を純化。
- **v1.0**：依存先を「基底措定（BASE）」へ更新。巡航と再編相 $M_\Delta$ の二重構造を明記。
